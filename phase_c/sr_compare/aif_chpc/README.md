# AI Feynman on CHPC

AI Feynman 2.0.7 cannot build on the DGX (no gfortran, no sudo), so it
runs on CHPC where gfortran 8.5 exists. Build recipe that worked past
the two packaging traps (venv `~/mat_theory/aif_venv` on notchpeak):

```
module load python/3.11.7            # numpy.distutils needs py<=3.11
pip install "numpy<1.26"             # last numpy with distutils
export SKLEARN_ALLOW_DEPRECATED_SKLEARN_PACKAGE_INSTALL=True
pip install --no-build-isolation aifeynman   # setup.py imports numpy
```

`aif_run.py` runs the three benchmark tasks (data files generated by
`../datasets.py`, features then r = 1/kappa, whitespace-separated) with
BF_try_time=30, 14ops, polyfit_deg=3, NN_epochs=400, and writes
`aif_out.json` with the tail of each solution file. Submit with
`sbatch_aif.sh` (notchpeak-guest / owner-guest); full-fit only: 5-fold CV at AI Feynman cost was deliberately
skipped, so its comparison row is expression + in-sample only.

Remote layout: `~/mat_theory/aif/{aif_run.py,sbatch_aif.sh,data/*.txt}`.
